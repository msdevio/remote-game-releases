# Remote Game — versions publiées

**Remote Game** est un client Remote Play pour PS5 et PS4 sur téléphone, tablette et Android TV, pensé pour jouer
**à deux manettes**, à la maison comme à distance.

Ce dépôt ne contient que les versions publiées. Chacune comprend :

| Fichier | Contenu |
|---|---|
| `remote-game-x.y.z.apk` | l'application à installer |
| `remote-game-x.y.z-source.tar.gz` | son code source complet |
| `remote-game-x.y.z-third-party-sources.tar.gz` | les sources des bibliothèques téléchargées à la compilation (OpenSSL, json-c, miniupnpc, Opus) |
| `SHA256SUMS.txt` | les empreintes des fichiers |

## Installer

1. Télécharge l'APK de la [dernière version](../../releases/latest) sur ton téléphone, ta tablette ou ta box Android TV.
2. Ouvre-le et autorise l'installation quand Android le demande.
3. Ensuite, Remote Game se met à jour tout seul (Réglages › Mises à jour automatiques).

Android 11 ou plus récent. Il faut un compte PSN et une PS5 (ou une PS4) avec la lecture à distance activée.

# Remote Game — published versions

**Remote Game** is a PS5 and PS4 Remote Play client for Android phones, tablets and Android TV, built for playing
**with two controllers**, at home or away.

This repository only holds published versions: for each one, the APK, its complete source code, the sources of the
third-party libraries downloaded by the build, and the SHA-256 checksums. Install the APK of the
[latest version](../../releases/latest) (Android 11 or newer); the app then updates itself.
